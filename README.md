# ✈️ Toy F-35 Flight Simulator & 3D Model

An interactive 3D WebGL flight simulator and 3D printable model of a stylized toy F-35 Lightning II jet. Built with vanilla WebGL, procedural Web Audio sound synthesis, and real-time flight physics.

## 🎮 Live Demo
Play the flight simulator online via GitHub Pages:
https://<your-username>.github.io/<repo-name>/

## 🕹️ Controls
- **Pitch Up / Down**: S / W (or Down / Up Arrow keys)
- **Bank Left / Right**: A / D (or Left / Right Arrow keys)
- **Rudder Yaw**: Q / E
- **Throttle**: Shift (Speed Up) / Ctrl (Slow Down)
- **Afterburner Boost**: Space (Super thrust + animated flame plume)
- **Pitch Mode**: I key or top button (toggle between **Flight Stick** and **Arcade** modes)
- **Camera Views**: C key (Chase Cam, Cockpit HUD, Flyby Cam)
- **Time of Day**: Switch between Noon ☀️, Sunset 🌅, and Night 🌙
- **Audio**: M key to toggle sound effects

## 📦 3D Model Assets
- 	oy_f35_jet.stl: Stand-free 3D printable model for 3D slicers (Cura, Bambu Studio, PrusaSlicer).
- 	oy_f35_jet.obj & 	oy_f35_jet.mtl: 3D mesh for Blender, Unity, or Unreal Engine.
- 	oy_f35_viewer.html: Standalone 3D model inspection viewer.
